# Pivnice Pizza POKR — Verze 1 (Zlatá Hladinka)

Tmavý prémiový koncept moderní znojemské pivnice s důrazem na ocenění **Hvězda sládků**, nově zrekonstruované prostory, interaktivní menu (pivo, pizza, burgery, řízky, fokáče), zábavní zónu (kulečník, šipky, fotbálek) a poptávkový formulář na catering a soukromé akce.

- **Web / Projekt:** `pivnicepizzapokr.cz`
- **Nasazení:** Statický web připravený k okamžitému nasazení na Vercel (bez nutnosti build kroku).
