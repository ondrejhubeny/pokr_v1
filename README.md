# Pivnice Pizza POKR — Verze 1 (Pilsner Edition: Styl V3 × Barvy V2)

Sloučení moderního stylu, rozvržení, typografie (`Oswald` + `Space Grotesk`), vyhledávatelné **Menu Tabule** a interaktivního **Catering konfigurátoru** z původní **Verze 3** s barevným laděním **Pilsner Urquell** (hluboká pivovarská zelená, čistá krémová/bílá, červené detaily a zlatá Hvězda sládků) z **Verze 2**.

- **Web / Projekt:** `pivnicepizzapokr.cz`
- **Nasazení:** Statický web připravený k okamžitému nasazení na Vercel.
